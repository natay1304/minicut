# Подключение Claude к minicut (MCP)

MCP-сервер даёт Claude те же операции, что есть в редакторе: импорт, нарезка, оверлеи, подписи, экспорт. Ты смотришь результат в браузере вживую, Claude правит проект через инструменты.

```
Claude ──MCP (stdio)──► src/mcp.js ──HTTP──► minicut (http://127.0.0.1:4317) ◄── браузер
```

## 1. Установка
Нужны Node 20+ и ffmpeg (`brew install ffmpeg`), затем в папке проекта:

```bash
npm install
npm run mcp:install              # покажет конфиг и команды с твоими путями
npm run mcp:install -- --code    # зарегистрирует в Claude Code (для всех папок)
npm run mcp:install -- --desktop # допишет конфиг Claude Desktop и Cowork (с резервной копией)
```

Скрипт подставляет абсолютные пути к `node` и `src/mcp.js` этой копии проекта. Вручную то же самое:

- **Claude Code:** `claude mcp add --scope user minicut -- /путь/к/node /путь/к/minicut/src/mcp.js`. Внутри папки проекта уже есть `.mcp.json`, там MCP подключается сам.
- **Claude Desktop и Cowork:** добавь блок `mcpServers` в `claude_desktop_config.json` (на macOS он лежит в `~/Library/Application Support/Claude/`), затем полностью перезапусти приложение:
  ```json
  { "mcpServers": { "minicut": { "command": "/абсолютный/путь/к/node", "args": ["/абсолютный/путь/к/minicut/src/mcp.js"] } } }
  ```
- **Другой MCP-клиент:** команда `node /путь/к/minicut/src/mcp.js`, транспорт stdio.

Нужен именно абсолютный путь к `node`: приложения не видят `nvm` и не найдут просто `node`. Путь покажет `which node`. После смены версии Node обнови конфиг (`npm run mcp:install` перезапишет).

## 2. Проверка
1. Новая сессия Claude, спроси: «Покажи проект minicut» — Claude вызовет `get_project`.
2. Открой http://127.0.0.1:4317. Если сервер не запущен, MCP сам поднимет его при первом запуске клиента и остановит вместе с ним. Хочешь, чтобы редактор жил отдельно, запусти `npm start` заранее, MCP подключится к нему.
3. Правка от Claude появляется в браузере сразу, без перезагрузки.

## 3. Как попросить Claude смонтировать
Примеры:
- «Импортируй `/Users/me/Videos/talk.mp4`, убери паузы и положи на основную дорожку».
- «Добавь поверх с 3-й секунды `/Users/me/Videos/graphic.webm` на вторую дорожку, масштаб 0.5, в правый верх».
- «Загрузи субтитры из `/Users/me/Videos/talk.srt`, подпись стиля sub подними выше».
- «Расшифруй видео, найди повторные дубли, оставь последние и сделай субтитры» (сначала один раз `npm run setup:speech`).
- «Собери быстрый предпросмотр», а финальный `render` только после твоего «собирай».

Claude получает краткую инструкцию автоматически (поле `instructions` MCP-сервера). Ключевые правила:
- время в секундах; дорожки `main` (клипы идут подряд) и `overlay` … `overlay10` (клип стоит по `start`, больший номер рисуется выше);
- сначала `get_project`, потом маленькие шаги и проверка результата; любое изменение отменяется `undo`;
- `scale: 1` покрывает холст, `x` и `y` — смещение в долях холста, `volume` от 0 до 2;
- экспорт только по просьбе, путь `.mp4` внутри разрешённых папок.

## 4. Инструменты
Полный список с соответствием операциям HTTP API: [API.md](API.md). Кратко: `get_project`, `import_media`, `add_clip`, `split`, `trim`, `remove_clip(s)`, `move_clip`, `move_clip_to_track`, `add/remove_overlay_track`, `set_clip(s)`, `scale_speed`, `get_frame`, `get_media_frame`, `probe`, `ffmpeg_help`, `ffmpeg_run`, `detect_silence`, `remove_silence`, `set_canvas`, `add/set/remove_text`, `set_style`, `import_subtitles`, `import_transcript`, `list/new/load/save_project`, `undo`, `redo`, `preview`, `render`, `cancel_render`, расшифровка речи (`speech_status`, `transcribe`, `get_transcript`, `find_in_transcript`, `find_repeats`, `cut_source_range`, `subtitles_from_transcript`); подробнее: [SPEECH.md](SPEECH.md).

### ffmpeg через MCP
Claude может пользоваться ffmpeg без интерфейса, но только через проверенные инструменты (команду собирает minicut, оболочки нет):

| Инструмент | Что делает |
| --- | --- |
| `get_frame` | кадр проекта на нужной секунде таймлайна, как в экспорте (раскладка, кадрирование, подписи), JPEG. Claude проверяет свой монтаж глазами |
| `get_media_frame` | кадр исходного файла или медиа проекта |
| `probe` | данные файла: формат, длительность, дорожки, кодеки |
| `ffmpeg_help` | что умеет ffmpeg на этом компьютере: фильтры, кодеки, форматы, параметры фильтра |
| `set_clip` с `speed`, `vfilters`, `afilters` | скорость клипа (0,25–4) и цепочки фильтров ffmpeg на клипе: цвет, размытие, шумоподавление, компрессор и т. д. Применяются в экспорте и быстром предпросмотре |
| `scale_speed` | ускорить или замедлить весь проект в N раз вместе с подписями и оверлеями |
| `ffmpeg_run` | собрать новый файл: стабилизация, цветокоррекция, музыка, генерация фонов, конвертация, GIF. Результат можно сразу добавить в медиатеку (`importAs`) |
| `render` с `videoCodec`, `videoBitrate` | H.264 (по умолчанию), H.265, VP9 (.webm), ProRes (.mov) |

Ограничения безопасности `ffmpeg_run` и фильтров клипа:
- входы и выход только в разрешённых папках (`MINICUT_ROOTS`), без скрытых;
- существующий файл не перезаписывается без `overwrite: true`, исходники проекта не перезаписываются никогда;
- нет сети и протоколов `file:`, `http:`, `concat:`; запрещены фильтры, читающие файлы или выполняющие команды (`movie`, `subtitles`, `lut3d`, `sendcmd` и др.) и параметры `textfile`, `fontfile`;
- на клипе недоступны фильтры, меняющие длительность (`trim`, `fps`, `reverse`, `atempo`…): для скорости есть `speed`;
- одновременно работает одна задача ffmpeg, её останавливает `cancel_render`, таймаут по умолчанию 20 минут;
- звук-только результаты пока нельзя положить на таймлайн (в медиатеку добавляются только видео).

## 5. Если что-то не работает
| Симптом | Причина и что сделать |
| --- | --- |
| Инструментов minicut нет | Приложение не перезапущено полностью, или в конфиге не абсолютный путь к `node`. Запусти `npm run mcp:install` и перезапусти приложение. |
| «server is not reachable» | Порт 4317 занят чужим процессом или сервер упал. Проверь `lsof -i :4317`, лог MCP в окне клиента, задай другой порт переменной `PORT` в `env` конфига. |
| «вне разрешённых папок» | Файл вне домашней и временной папок. Добавь папку в `MINICUT_ROOTS` (список через `:`) в `env` конфига. |
| Скрытая папка | Пути через папки с точкой (`~/.ssh`, `~/.config`) закрыты намеренно. |
| В Cowork «не вижу файл» | Cowork работает в изолированной среде: давай Claude пути на твоём Маке, MCP выполняется на хосте. |
| Правки не видны в браузере | Открыт другой порт, или вкладка потеряла соединение: обнови страницу. |

Переменные в конфиге клиента задаются так:
```json
"minicut": { "command": "...", "args": ["..."], "env": { "PORT": "4318", "MINICUT_ROOTS": "/Users/me/Videos:/tmp" } }
```

## 6. Безопасность
Сервер слушает только `127.0.0.1`, проверяет `Host` и `Origin`, импорт и экспорт ограничены `MINICUT_ROOTS`. Не пробрасывай порт наружу: у API нет авторизации.
