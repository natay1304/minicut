# minicut v2 — доработки (поверх SPEC.md)

Цель: монтаж вертикальных рилсов 1080×1920 из видео «говорящая голова» с Pixel + врезки с экранами. Всё, что умеет UI, должно быть доступно и через `/api/op` и MCP.

## Важные факты об окружении
- ffmpeg из Homebrew **без libass и freetype**: фильтров `subtitles`, `ass`, `drawtext` НЕТ. Текст рисовать в PNG (прозрачный фон) через `@napi-rs/canvas` и накладывать фильтром `overlay`.
  Для множества подписей не делать по входу на каждую: собрать одну «текстовую дорожку» через `-f concat` по списку PNG с `duration` (пустой прозрачный PNG для пауз) и один `overlay` поверх видео.
- Видео с Pixel: 1920×1080 + side data `rotation=90/270`. `probe` должен возвращать **отображаемые** размеры (1080×1920, с учётом поворота), `ffmpeg` автоповорачивает при декодировании.
- Только `localhost`, никаких сетевых вызовов.

## Модель данных v2 (миграция из v1 при загрузке: старые `clips` → дорожка `main`)
```json
{
  "version": 2, "name": "reel-a",
  "canvas": { "width": 1080, "height": 1920, "fps": 30 },
  "media": [ ... как раньше, width/height уже с учётом поворота ... ],
  "tracks": [
    { "id": "main",    "kind": "ripple",  "clips": [ ... ] },
    { "id": "overlay", "kind": "free",    "clips": [ ... ] }
  ],
  "texts": [ { "id": "t1", "start": 1.2, "end": 3.0, "text": "...", "style": "sub" } ],
  "styles": { "sub": { "font": "JetBrains Mono", "weight": 700, "size": 62, "color": "#F3E9DC", "shadow": { "dx": 3, "dy": 3, "blur": 6, "color": "#000000AA" }, "x": 0.5, "y": 0.64, "align": "center" } }
}
```
- `main`: клипы идут подряд (ripple), позиция = сумма предыдущих. Аудио берётся отсюда.
- `overlay`: свободные клипы с полем `start` (позиция на таймлайне), по умолчанию без звука (`muted: true`). Клип показывается поверх main в интервале `[start, start + (out-in)]`.
- Поля клипа: `id, mediaId, in, out, name, scale (1.0 = cover холста), x, y (смещение в долях холста, 0 = центр), volume (0..2, по умолчанию 1), muted, fadeIn, fadeOut (сек), start (только overlay)`.
- Масштаб «cover»: клип масштабируется, чтобы закрыть холст, затем `scale` множит, `x/y` сдвигают; лишнее обрезается.

## Операции (дополнение к существующим, все через `/api/op`, все с undo/redo)
Существующие `addClip, trim, move, split, splitAt, remove, undo, redo, detectSilence, importMedia` сохраняют сигнатуры; новый необязательный аргумент `track` (`"main"` по умолчанию).
- `setClip(clipId, {scale?, x?, y?, volume?, muted?, fadeIn?, fadeOut?, name?, start?})`
- `removeSilence({clipId?, noiseDb=-30, minDur=0.4, pad=0.08})` — режет клипы main по тишине и удаляет тихие куски (по умолчанию все клипы main).
- `setCanvas({width, height, fps})`
- `addText({start,end,text,style?})`, `setText(id, patch)`, `removeText(id)`, `setStyle(name, patch)`
- `importSubtitles(path)` — `.srt` и `.ass` (минимально: Dialogue-строки, время, текст) → `texts`
- `setClips(clipIds, patch)` — групповое изменение (для мультивыделения), `removeClips(ids)` со сдвигом.
- `ripple`-удаление по умолчанию в main; в overlay просто удаление.
- Проекты: `listProjects()`, `newProject(name)`, `loadProject(name)`, `saveProjectAs(name)`; файлы `data/projects/<name>.json`, активный проект запоминается в `data/current.txt`. Автосохранение в активный проект после каждой мутации.
- Транскрипция в этой фазе НЕ делаем (ASR пока не выбран). Заложить только операцию `importTranscript(mediaId, words:[{start,end,text}])`, сохраняющую слова в `media[].words`, и операцию `cutByText(mediaId, {from, to})` не нужна.

## Рендер
- Вход: `{output, width?, height?, fps?, crf=18, preset='medium', audioBitrate='192k', loudnorm=false}`.
- Сборка одним `filter_complex`: чёрный холст → main клипы (trim/atrim, setpts, scale/crop по `scale/x/y`, concat) → overlay клипы (`overlay` с `enable='between(t,a,b)'`, `setpts` со сдвигом на `start`) → текстовая дорожка из PNG → выход.
- Аудио: main клипы с `volume`, `afade` in/out на каждом клипе (по умолчанию короткий 0.02 с кроссфейд-антиклик на склейках), `muted` → тишина той же длины; overlay-аудио только если `muted:false`; опционально `loudnorm` I=-16.
- Прогресс: `-progress pipe:1`, SSE `render-progress {pct, fps, eta}`.
- Отмена: `POST /api/render/cancel` убивает ffmpeg и удаляет недописанный файл (только его).
- Один рендер за раз.
- Быстрый предпросмотр: `POST /api/preview` рендерит низкокачественный прокси (540×960, ultrafast, crf 30) в `data/preview.mp4` и отдаёт по `/preview.mp4`.

## UI (фаза 2)
- Две дорожки на таймлайне (main, overlay), перетаскивание клипов overlay по времени, привязка (snap) к краям соседних клипов и плейхеду.
- Мультивыделение (Shift/Cmd+клик, рамка), групповое удаление, названия клипов (двойной клик).
- Панель свойств выбранного клипа: масштаб, X/Y, громкость, mute, fade in/out.
- Холст 1080×1920 в превью: рамка «безопасной зоны», предпросмотр масштаба/позиции, оверлей-дорожка поверх основной, текстовые подписи.
- Панель текста: список подписей, стиль (шрифт, размер, цвет, тень, позиция), импорт `.srt/.ass`.
- Меню проектов (список, новый, сохранить как, открыть).
- Диалог экспорта: разрешение, fps, качество (crf), loudnorm, прогресс, кнопка «Отмена», кнопка «Быстрый предпросмотр».
- Кнопка «Убрать паузы» с параметрами порога и длительности.
