# Расшифровка речи

minicut распознаёт речь **локально**: видео и звук не уходят в интернет. Под капотом [whisper.cpp](https://github.com/ggml-org/whisper.cpp) (лицензия MIT) и модель Whisper. Слова с точным временем сохраняются в проект, поэтому можно искать фразы, вырезать куски и делать субтитры по тексту, а Claude делает то же через MCP.

```
видео ─ffmpeg─► звук 16 кГц ─whisper.cpp─► слова с временем ─► проект (media[].words)
                                                                   │
                       поиск фраз · дубли · вырезание · субтитры ◄─┘
```

## Установка

Нужны ffmpeg и Node 20+ (как для самого minicut), затем в папке проекта:

```bash
npm run setup:speech
```

Команда проверяет, что уже есть, показывает план и просит подтверждение (без терминала добавьте `--yes`).

| Система | Что делает команда |
| --- | --- |
| macOS | ставит whisper.cpp через Homebrew (`brew install whisper-cpp`); если Homebrew нет, подскажет, где его взять |
| Windows | скачивает готовый архив whisper.cpp с GitHub Releases в `%USERPROFILE%\.minicut\speech\bin` и распаковывает |
| Linux | показывает команды сборки (нужны git, cmake, компилятор); путь к `whisper-cli` укажите в `MINICUT_WHISPER_BIN` |

Затем команда скачивает модель с [Hugging Face](https://huggingface.co/ggerganov/whisper.cpp) в `~/.minicut/speech/models`. По умолчанию это `large-v3-turbo-q5_0` (около 570 МБ): хорошо понимает русский и быстрая. Другие модели:

```bash
npm run setup:speech -- --model small      # быстрее и легче, но хуже на русском (~470 МБ)
npm run setup:speech -- --model medium     # точнее (~1,5 ГБ)
npm run setup:speech -- --check            # только показать состояние
```

Если расшифровку просят, а ничего не установлено, minicut отвечает понятной ошибкой с этой командой.

### Windows

- Программы Homebrew на Windows нет, поэтому скрипт берёт готовый архив с релизов whisper.cpp. Если название архива изменится и скрипт его не найдёт, скачайте программу вручную, распакуйте в `%USERPROFILE%\.minicut\speech\bin` или укажите путь в `MINICUT_WHISPER_BIN`.
- ffmpeg ставится отдельно (например, `winget install Gyan.FFmpeg` или с [ffmpeg.org](https://ffmpeg.org)), он должен быть в `PATH`.
- Пути указывайте как `C:\Users\имя\Videos\talk.mp4`, список папок в `MINICUT_ROOTS` разделяйте `;`.
- Разработано и проверено на macOS. Работу на Windows проверяют автотесты на уровне выбора архива и разбора результата, живой запуск на Windows нужно проверить.

## Как пользоваться

**В интерфейсе.** Панель «Расшифровка» справа: выберите видео и язык, нажмите «Расшифровать». Прогресс виден в панели, остановить можно кнопкой «Отмена». Дальше:
- клик по фразе переводит плейхед на это место;
- «Вырезать» удаляет фразу из основной дорожки;
- «Найти дубли» помечает повторные дубли и подсказывает, какой оставить (последний);
- «Субтитры из текста» создаёт подписи по клипам основной дорожки.

**Через Claude (MCP).** Достаточно попросить: «расшифруй видео, найди повторы, оставь последние дубли и сделай субтитры». Инструменты:

| Инструмент | Что делает |
| --- | --- |
| `speech_status` | установлено ли распознавание, что делать, если нет |
| `transcribe` | расшифровывает медиа (язык лучше указать: `ru`, `en`) |
| `get_transcript` | текст фразами с временем, можно по диапазону (экономит токены) |
| `find_in_transcript` | где сказана фраза (допускает близкие формулировки) |
| `find_repeats` | повторные и оборванные дубли, подсказка оставить последний |
| `cut_source_range` | вырезать интервал исходника из основной дорожки |
| `subtitles_from_transcript` | собрать подписи по таймлайну |

Типичный порядок для ролика без повторов: `transcribe` → `find_repeats` → `cut_source_range` для всех дублей, кроме последнего → `remove_silence` → `subtitles_from_transcript`. Любой шаг отменяется `undo`.

## Настройки

| Переменная | Назначение |
| --- | --- |
| `MINICUT_HOME` | папка для программ и моделей (по умолчанию `~/.minicut`) |
| `MINICUT_WHISPER_BIN` | путь к своему `whisper-cli` |
| `MINICUT_WHISPER_MODEL` | путь к своему файлу модели `ggml-*.bin` |

## Советы и ограничения

- Язык лучше указывать явно: автоопределение иногда ошибается на коротких записях.
- Время слов получается из модели, поэтому у границ слов возможна неточность в десятые доли секунды. Для резки используйте `pad` и проверяйте результат на пробном просмотре.
- Расшифровка занимает от нескольких секунд до минут. На Mac с процессором Apple 3-минутное видео обрабатывается примерно за 15 секунд.
- Модель может ошибаться в именах и терминах. В `transcribe` можно передать `prompt` со списком слов, которые встретятся в речи.
- Слова хранятся в файле проекта (около 13 КБ на 3 минуты речи) и не попадают в ответ `get_project`, там только их число.
