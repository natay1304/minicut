# Безопасность

minicut — локальное приложение: сервер слушает только `127.0.0.1`, проверяет `Host` и `Origin`, принимает только JSON и работает с файлами внутри `MINICUT_ROOTS`. Не публикуй порт наружу (через туннель, прокси или `0.0.0.0`): у API нет авторизации.

Нашёл уязвимость? Не открывай публичный issue, а напиши через раздел Security → Report a vulnerability в репозитории.
