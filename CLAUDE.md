# minicut: инструкции для Claude

## Если тебя просят смонтировать видео
Используй MCP-инструменты `minicut` (подключение: [docs/MCP.md](docs/MCP.md)), а не правь файлы проектов в `data/`. Начни с `get_project`, работай маленькими шагами, проверяй результат, финальный `render` только по просьбе пользователя. Пользователь видит проект вживую на http://127.0.0.1:4317. Если инструментов нет, скажи об этом и дай команду `npm run mcp:install`.

## Если тебя просят разрабатывать
- Структура: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), API: [docs/API.md](docs/API.md).
- Проверка перед коммитом: `npm run lint && npm run format:check && npm test`.
- Тесты изолированы через `MINICUT_DATA`. Никогда не запускай сервер, MCP или тесты против настоящей папки `data/` без временной `MINICUT_DATA`: там проекты пользователя.
- Модули фронтенда не импортируют друг друга по кругу; обратные вызовы идут через `public/js/hooks.js`.
- Новая операция: логика в `src/ops/`, маршрут в `src/routes/api.js`, тул в `src/mcp.js`, тест в `test/`, строка в `docs/API.md`.
